# Changelog

## Version 1.1.0
- Added the ability to pin clipboard history items.
- Improved accessibility permissions flow.

Thanks for using clip — feedback is always welcome!

## Version 1.0.0

- Initial release of clip — a minimal clipboard manager for macOS.
- Automatically saves your last copied text items.
- Click any item in the menu bar to paste it instantly.
- Adjustable history limit — choose between 10, 20, or 50 items.
- Lives in the menu bar only — no dock icon, stays out of your way.
